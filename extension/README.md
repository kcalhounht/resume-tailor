# Resume Tailor extension

Chrome/Edge Manifest V3 extension that sends the current tab’s job posting into Resume Tailor’s **Generate resume** tab.

## Load unpacked

1. Open `chrome://extensions` and enable **Developer mode**.
2. **Load unpacked** → select this `extension/` directory.
3. Options → set the Resume Tailor site if it is not `http://localhost:3000`.

On a job page, open the popup and click **Send job to Resume Tailor**.
